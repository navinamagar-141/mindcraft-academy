# MindCraft Academy product summary

## Purpose

MindCraft Academy is a Pokhara, Nepal website for practical, mentor-guided technology learning. It helps visitors understand the available Mentorship Intern Programs, review the work and culture of the academy, and start a conversation with the team.

## Audience

The primary audience is students and early to mid-career professionals in Pokhara who want practical experience in software development, design, security, or digital marketing.

## Programs

The site presents nine Mentorship Intern Programs. Each has a Basic tier lasting 6 weeks and an Advanced tier lasting 10 weeks:

1. MERN Stack
2. Full Stack Development
3. Python
4. Frontend Development
5. Backend Development
6. UI/UX Design
7. Cybersecurity
8. Java
9. Digital Marketing

## Main features

- Homepage with the Discover, Develop, Deploy message and an interactive practice exercise.
- Program index and individual program pages with focus areas, tier details, weekly syllabus content, and syllabus inquiry.
- Book Consultation modal with WhatsApp and a server-side form that accepts an optional CV.
- Student project showcase and campus culture page.
- Blog listing, author-type sections for students, teachers, and team, and individual articles.
- Footer with contact details, Google Maps link, social links, and Brandbuilder link.

## Out of scope

The site does not include user accounts, payments, enrollment management, a database, a CMS, an admin dashboard, or a full learning management system. Blog content, program content, tools, and practice questions are maintained in project files.
